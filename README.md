# Практические работы

Минималистичный одностраничный каталог учебных проектов.

## Возможности

- Просмотр опубликованных версий проектов в браузере.
- Скачивание исходного кода каждого проекта в ZIP.
- Адаптивная вёрстка для мобильных и настольных экранов.
- Без сборки и зависимостей: чистые HTML, CSS и ссылки на GitHub.

## Публикация на Cloudflare Pages

Подключите репозиторий `sk8teJ/z8` через **Workers & Pages → Create application → Pages → Connect to Git**.

Настройки:
- Production branch: `main`
- Framework preset: `None`
- Build command: оставить пустым
- Build output directory: `.`

## Адреса предпросмотра

Кнопки просмотра рассчитаны на Pages-проекты с такими именами: `z1`, `z2`, `z3`, `zadanie4`, `z5`, `z6`. Если при публикации будут выбраны другие имена, обновите соответствующие адреса в `index.html`.

ZIP-ссылки ведут на архивы ветки `main` соответствующих публичных GitHub-репозиториев.
